# Retained design references

Last updated: 2026-10-22.

Original browser recordings and external-site captures retained for future design comparison. These are reference evidence, not assets licensed or approved for the Sophomores production UI.

- `analogueagency_entry*.mov`: original entry and mouse-interaction recordings.
- `desktop-*.jpg`, `mobile-*.jpg`: Blink reference stills.
- Numbered `01`–`18` PNGs: Analogue, Má and pricing/video reference captures described in the [integration specification](../../docs/reference/integration-specification.md).
- `18-pricing-video-entry-motion.png` was captured too early to establish choreography; it is not accepted timing evidence.

Local implementation screenshots are regenerable QA output and are intentionally not collected here. The reference specification records rejected implementations and outstanding product decisions; retaining the references does not approve those implementations.
