  개별 문건 수정 시 해당문 사용 전 같은 필드 ID와 상품 버전을 동기화하고 대조 검토를 기록한다. 어느 언어도 자동 우선하지 않는다. 차이는 함께 해결한다.

빈칸에는 확인된 사실과 근거를 적는다. 선택·비해당 항목은 “해당 없음 — 사유”로 적어도 된다. 공란은 결정이 아니다. 종류·구간 행은 필요할 때만 늘린다. 종류별 반복 필드·참조는 고정 필드 ID 뒤에 `[variant ID]`를 붙인다(예: `TICKET.02[variant ID]`). 가격·수수료·할인의 적용 범위에도 같은 복합 참조를 쓴다. 고객 약속에 관한 미결 사항은 출시 전에 해결한다.

**기존 승인 결정:** 이메일·전화번호 확인을 마친 계정은 구매할 수 있으며 클럽 가입 승인은 별개다. 구매 자격 방향이지 결제 활성화나 입장 권리의 검증은 아니다.

**기능 경계:** PortOne 로컬 결제·복구 작업은 선정 PG 승인, 결제수단 활성화, 티켓 발급·조회·사용 처리·환불 실행을 증명하지 않는다. 제안한 약속마다 별도 확인한다. 결제 성공만으로 유효 입장 티켓이 되지 않는다.
